# Q&A ログ (ADR形式)

Djangoチュートリアル中にClaudeへ質問した内容を記録する。

## ファイル命名規則

```
YYYYMMDD-NNN-質問の要約.md
```

例: `20260525-001-マイグレーションとは何か.md`

## テンプレート

```markdown
# [質問タイトル]

**日付**: YYYY-MM-DD  
**チュートリアル箇所**: （例: Part 1 / モデル定義）  
**ステータス**: 解決済み

## 質問

（質問内容）

## 回答

（Claudeの回答）

## 補足

（関連リンクや追加メモがあれば）
```

## 特記事項（重複した質問）

同じ質問が2回以上あった場合は下記にリストアップする。
理解の定着が必要な概念として優先的に復習すること。

| 質問 | 回数 | 関連ファイル |
|------|------|------------|
| （例）マイグレーションとモデルの関係 | 2 | 20260525-001-..., 20260601-010-... |
