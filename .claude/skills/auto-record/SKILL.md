# auto-record

会話の内容を評価し、記録価値に応じて自動または確認付きで保存するスキル。

## When to Use

- Django の概念・コマンド・エラーについて質問に回答した後
- 環境設定や開発ツールについて有益な情報が出た後
- ユーザーが「記録して」「残して」「覚えておいて」と言ったとき
- セッション終了前のまとめ記録

## Evaluation Criteria

会話内容を以下の基準で評価する：

| 確信度 | 判定条件 | アクション |
|--------|----------|-----------|
| **高（自動）** | 質問→回答が明確に完結している Django Q&A | ADR を自動作成 + index.html 更新 |
| **高（自動）** | ユーザーの好み・フィードバック・作業スタイルが判明した | memory に自動保存 |
| **中（確認）** | 役立ちそうだが一時的・文脈依存かもしれない情報 | `confirm` スキルで記録先を確認 |
| **低（スキップ）** | 単純なファイル編集・作業依頼のみ（概念的学びなし） | 何もしない |

**ADR 候補の典型例**:
- Django のモデル・ビュー・URL・テンプレートの仕組みに関する質問
- マイグレーション・管理サイト・ORM の使い方
- エラーメッセージの原因と解決法
- 公式ドキュメントの補足説明

**memory 候補の典型例**:
- ユーザーが「こうしてほしい」と明示した好み
- 回答スタイルへのフィードバック
- 特定のツールや方法を好むことが判明した

## Auto-Record Process

### ADR の作成手順

1. **既存 ADR の連番を確認**
   ```
   ls .claude/adr/*.md | sort | tail -1
   ```
   取得した最大番号 + 1 を NNN とする（例: `001` → `002`）。ADR がなければ `001`。

2. **ファイル名を決める**
   ```
   YYYYMMDD-NNN-質問の要約.md
   例: 20260604-002-仮想環境の起動方法.md
   ```
   要約は 15〜25 文字程度の日本語で。

3. **ADR ファイルを作成** (`.claude/adr/<ファイル名>`)
   ```markdown
   # [質問タイトル]

   **日付**: YYYY-MM-DD
   **チュートリアル箇所**: （例: 環境設定 / Part 1）
   **ステータス**: 解決済み

   ## 質問
   （質問内容を要約）

   ## 回答
   （回答の要点を記載）

   ## 補足
   （関連リンクや追加メモ。なければ省略可）
   ```

4. **index.html の QA_DATA 配列を更新**
   以下のオブジェクトを `QA_DATA` 配列の先頭に追加する：
   ```javascript
   {
     id: "YYYYMMDD-NNN",
     date: "YYYY-MM-DD",
     part: "Part X",        // 不明なら "" を使う
     title: "質問のタイトル",
     status: "解決済み",
     file: "YYYYMMDD-NNN-要約.md",
     duplicate: false
   }
   ```

### memory の保存手順

`/Users/akinobu_oka/.claude/projects/-Users-akinobu-oka-goals-django-tutorial/memory/` に保存する。
既存のメモリファイルと重複しないか `MEMORY.md` を確認してから作成する。
フォーマットは `feedback_*.md` または `user_*.md` に従う。

## Confirm Process

確信度が「中」の場合は `confirm` スキルを呼び出す：

```
選択肢の例:
- ADRに記録する — .claude/adr/ にファイルを作成する
- メモリに保存する — memory/ に保存する
- スキップする — 今回は記録しない
```

ユーザーの回答に応じてアクションを実行する。

## Notes

- 同じ質問が過去にある場合、index.html の `DUPLICATES` 配列にも追記する
- 「チュートリアル箇所」が不明な場合は会話の文脈から推定する
- 回答の要点は箇条書きで簡潔に（原文ママでなくてよい）
